# dsh-auto-workflow v1.0.1

这是 **dsh-auto-workflow** 的命名整理版本。没有运行时、节点图、运行状态或示例业务数据格式变化；保留 `v1.0.0` 作为首个功能发布。

## 本次变化

- GitHub 仓库由 `lyingloong/dsh-agent-team-workflow` 更名为 [lyingloong/dsh-auto-workflow](https://github.com/lyingloong/dsh-auto-workflow)；旧 GitHub 链接由平台重定向。
- 文档、看板和 Release 的正式名称统一为 `dsh-auto-workflow`；`Auto Workflow` 仅作为短显示名，会话顶栏入口仍为“工作流”。
- `package.json` 的 repository、homepage、bugs 和 npm 描述同步到新仓库。
- 未增加远端 Issue/PR、push 或部署自动化；唯一主示例仍是 GitHub 项目的本地 clone 持续开发。

## 固定版本安装

```bash
dsh plugin --profile desktop add github:lyingloong/dsh-auto-workflow#v1.0.1
```

也可从 [本 Release](https://github.com/lyingloong/dsh-auto-workflow/releases/tag/v1.0.1) 下载 `dsh-auto-workflow-1.0.1.tgz`，再本地安装。安装后重启 DSH Host 并刷新 Web GUI。

`v1.0.0` 的 tag、Release 和安装包保持原样，未移动或覆盖；需要首个功能发布的固定基准时仍可使用 `#v1.0.0`。

## 验证

本版本沿用 1.0.0 的运行时与示例，只改元数据和名称。发布前重新运行完整本地回归与打包校验；具体结果和覆盖边界见[验证说明](https://github.com/lyingloong/dsh-auto-workflow/blob/v1.0.1/docs/verification.md)。
